## 💻 Featured Test Automation Frameworks

### 🧪 1. [UI-Test-Framework](https://github.com/Flexlikeuuu/UI-Test-Framework)
- **Role:** Automation Framework Architect / Lead Author
- **Tech Stack:** TypeScript/JavaScript, Playwright, Page Object Model (POM), Allure Report, GitHub Actions
- **Key Deliverables:**
  * Engineered a production-ready, site-agnostic UI automation framework built on strict **Page Object Model (POM)** and component-level abstractions.
  * Implemented Dependency Injection via custom Playwright fixtures, eliminating boilerplate code and ensuring complete isolation between parallel workers.
  * Configured multi-browser matrix pipelines (Chromium, Firefox, WebKit), headless/headed test profiles, deterministic trace collection, and automatic artifact capturing on failures.
  * Integrated directly with **GitHub Actions CI/CD** with automated test report publication and defect classification.

### 🔌 2. [API-Test-Framework](https://github.com/Flexlikeuuu/API-Test-Framework)
- **Role:** Automation Framework Architect / Lead Author
- **Tech Stack:** TypeScript/JavaScript, Playwright (APIRequestContext), Ajv Schema Validation, GitHub Actions
- **Key Deliverables:**
  * Architected a modular REST API test automation engine from scratch utilizing Playwright’s native networking layer for high-throughput microservice testing.
  * Implemented strict contract and payload validation using **Ajv (JSON Schema)**, fluent assertion wrappers, and automated status/header verification.
  * Engineered centralized session state handlers, dynamic multi-environment configuration switching, and synthetic data factories for deterministic test setup/teardown.
  * Embedded end-to-end integration workflows into CI quality gates with automated Slack/PR status triggers.
